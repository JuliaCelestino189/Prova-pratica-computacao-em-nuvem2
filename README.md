# Prova-pratica-computacao-em-nuvem


1-Fundamentos da computação em nuvem: 

Questão 1 - Qual a diferença entre IaaS e SaaS? Cite um explo de utilização de cada modelo 
IaaS é um modelo que oferece infraestrutura de TI pela internet, como servidores, armazenamento e redes. Um exemplo é utilizar uma máquina virtual na AWS. SaaS disponibiliza softwares prontos para uso pela internet, sem que o usuário precise administrar a infraestrutura. Um exemplo é o Google Drive.

Questão 2 - Uma empresa utiliza servidores proprios e também recursoa de um provedor de nuvem pública. Qual modelo de implatação em nuvem essa empresa utiliza?
A empresa utiliza a nuvem híbrida, pois combina sua infraestrutura própria com recursos de uma nuvem pública.

Questão 3 - Qual é a principal diferença entre máquina virtual e um contêiner?
A máquina virtual possui um sistema operacional próprio, enquanto o contêiner compartilha o sistema operacional do servidor. Por isso, os contêineres geralmente são mais leves e rápidos para iniciar.
